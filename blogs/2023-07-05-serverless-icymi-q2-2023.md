<p><img alt="" class="alignnone size-full wp-image-20849" height="529" src="https://d2908q01vomqb2.cloudfront.net/1b6453892473a467d07372d45eb05abc2031647a/2023/07/05/Picture-2.png" width="941" /></p>

<h2>AWS Lambda</h2> 
<p><img alt="" class="alignnone size-full wp-image-20850" height="260" src="https://d2908q01vomqb2.cloudfront.net/1b6453892473a467d07372d45eb05abc2031647a/2023/07/05/Picture-3.png" width="941" /></p> 
<p><a href="https://aws.amazon.com/blogs/compute/introducing-aws-lambda-response-streaming/" rel="noopener" target="_blank">Lambda introduced support for response payload streaming</a> allowing functions to progressively stream response data to clients. This feature significantly improves performance by reducing the time to first byte (TTFB) latency, benefiting web and mobile applications.</p> 
<p>Response streaming is particularly useful for applications with large payloads such as images, videos, documents, or database results. It eliminates the need to buffer the entire payload in memory and enables the transfer of responses larger than Lambda’s 6 MB limit, up to a soft limit of 20 MB.</p> 
<p>By configuring the Function URL to use the <strong>InvokeWithResponseStream</strong> API, streaming responses can be accessed through an HTTP client that supports incremental response data. This enhancement expands Lambda’s capabilities, allowing developers to handle larger payloads more efficiently and enhance the overall performance and user experience of their web and mobile applications.</p> 
<p><a href="https://aws.amazon.com/blogs/compute/java-17-runtime-now-available-on-aws-lambda/" rel="noopener" target="_blank">Lambda now supports Java 17</a> with <a href="https://aws.amazon.com/corretto" rel="noopener" target="_blank">Amazon Corretto</a> distribution, providing long-term support and improved performance. Java 17 introduces new language features like records, sealed classes, and multi-line strings. The runtime uses ZGC and Shenandoah garbage collectors to reduce latency. Default JVM configuration changes optimize tiered compilation for reduced startup latency. Developers can use Java 17 in Lambda through <a href="https://aws.amazon.com/console/" rel="noopener" target="_blank">AWS Management Console</a>, <a href="https://aws.amazon.com/serverless/sam/" rel="noopener" target="_blank">AWS SAM</a>, and <a href="https://aws.amazon.com/cdk/" rel="noopener" target="_blank">AWS CDK</a>. Popular frameworks like Spring Boot 3 and <a href="https://micronaut.io/2023/02/16/micronaut-framework-4-0-with-java-17-baseline/" rel="noopener" target="_blank">Micronaut 4</a> require Java 17 as a minimum. Micronaut provides a web service to generate example projects using Java 17 and AWS CDK infrastructure.</p> 
<p><a href="https://aws.amazon.com/blogs/compute/ruby-3-2-runtime-now-available-in-aws-lambda/" rel="noopener" target="_blank">Lambda now supports the Ruby 3.2 runtime</a>, enabling you to write serverless functions using the latest version of the Ruby programming language. This update enhances developer productivity and brings new features and improvements to your Ruby-based Lambda functions.</p> 
<p>Lambda <a href="https://aws.amazon.com/about-aws/whats-new/2023/06/aws-lambda-kafka-mq-event-sources-four-regions/" rel="noopener" target="_blank">introduced support for Kafka and Amazon MQ event sources in four additional Regions</a>. This expanded availability allows developers to build event-driven architectures using these messaging systems in more regions around the world, providing greater flexibility and scalability. It also supports <a href="https://aws.amazon.com/about-aws/whats-new/2023/05/aws-lambda-kafka-mq-event-sources-govcloud-regions/" rel="noopener" target="_blank">Kafka and Amazon MQ event sources in AWS GovCloud (US) Regions</a>, allowing government organizations to leverage the benefits of event-driven architectures in their cloud environments.</p> 
<p>Lambda also added support for <a href="https://aws.amazon.com/about-aws/whats-new/2023/06/aws-lambda-starting-timestamp-kafka-sources/" rel="noopener" target="_blank">starting from a specific timestamp for Kafka event sources</a>, allowing for precise message processing and useful scenarios like Disaster Recovery, without any additional charges.</p>

 <li>The <a href="https://serverlessland.com/content/paved-path/lift-and-shift-a-web-app-to-serverless/1-introduction" rel="noopener" target="_blank">Lift and Shift to Serverless</a> learning path provides guidance on migrating traditional applications to a serverless environment.</li> 
 <li><a href="http://s12d.com/lambda-fundamentals" rel="noopener" target="_blank">Lambda Fundamentals</a> is a 23-part video series providing practical examples and tips to help you get started with serverless development using Lambda.</li> 
</ul> 
<p>The new AWS Tech Talk, <a href="https://www.youtube.com/watch?v=L7N-_J1ky5g" rel="noopener" target="_blank">Best practices for building interactive applications with AWS Lambda</a>, helps you learn best practices and architectural patterns for building web and mobile backends as well as API-driven microservices on Lambda. Explore how to take advantage of features in Lambda, <a href="https://aws.amazon.com/api-gateway/" rel="noopener" target="_blank">Amazon API Gateway,</a> <a href="https://aws.amazon.com/dynamodb/" rel="noopener" target="_blank">Amazon DynamoDB</a>, and more to easily build highly scalable serverless web applications.</p> 
<h2>AWS Step Functions</h2> 
<p>The latest update to <a href="https://aws.amazon.com/step-functions/" rel="noopener" target="_blank">AWS Step Functions</a> <a href="https://aws.amazon.com/blogs/compute/deploying-state-machines-incrementally-with-versions-and-aliases-in-aws-step-functions/" rel="noopener" target="_blank">introduces versions and aliases</a>, allows users to run specific state machine revisions, ensuring reliable deployments, reducing risks, and providing version visibility. Appending version numbers to the state machine ARN enables selection of desired versions, even after updates. Aliases distribute execution requests based on weights, supporting incremental deployment patterns.</p> 
<p><img alt="" class="alignnone size-full wp-image-20851" height="560" src="https://d2908q01vomqb2.cloudfront.net/1b6453892473a467d07372d45eb05abc2031647a/2023/07/05/Picture-4.png" width="941" /></p> 
<p>This enhances confidence in state machine updates, improves observability, auditing, and can be managed through the Step Functions console or <a href="https://aws.amazon.com/cloudformation/" rel="noopener" target="_blank">AWS CloudFormation</a>. Versions and aliases are available in all supported AWS Regions at no extra cost.</p> 
<h3>AWS SAM</h3> 
<p><a href="https://docs.aws.amazon.com/serverless-application-model/latest/developerguide/what-is-sam.html" rel="noopener" target="_blank">AWS SAM CLI</a> has introduced a new feature called <a href="https://aws.amazon.com/blogs/compute/testing-aws-lambda-functions-with-aws-sam-remote-invoke/" rel="noopener" target="_blank">remote invoke</a> that allows developers to test Lambda functions in the AWS Cloud. This feature enables developers to invoke Lambda functions from their local development environment and provides options for event payloads, output formats, and logging.</p> 
<p><img alt="" class="alignnone size-full wp-image-20852" height="452" src="https://d2908q01vomqb2.cloudfront.net/1b6453892473a467d07372d45eb05abc2031647a/2023/07/05/Picture-5.png" width="941" /></p> 
<p>It can be used with or without AWS SAM and can be combined with <a href="https://aws.amazon.com/blogs/compute/accelerating-serverless-development-with-aws-sam-accelerate/" rel="noopener" target="_blank">AWS SAM Accelerate</a> for streamlined development and testing. Overall, the remote invoke feature simplifies serverless application testing in the AWS Cloud.</p> 
<h2>Amazon EventBridge</h2> 
<p>EventBridge announced an <a href="https://aws.amazon.com/about-aws/whats-new/2023/05/amazon-eventbridge-open-source-connector-kafka-connect/" rel="noopener" target="_blank">open-source connector for Kafka Connect</a>, providing seamless integration between EventBridge and Kafka Connect. This connector simplifies the process of streaming events from Kafka topics to EventBridge, enabling you to build event-driven architectures with ease.</p> 
<p>EventBridge has <a href="https://aws.amazon.com/about-aws/whats-new/2023/05/improved-end-to-end-latencies-amazon-eventbridge-event-buses/" rel="noopener" target="_blank">improved end-to-end latencies for event buses</a>, delivering events up to 80% faster. This enables broader use in latency-sensitive applications such as industrial and medical applications, with the lower latencies applied by default across all AWS Regions at no extra cost.</p> 
<h2>Amazon Aurora Serverless v2</h2> 
<p><a href="https://aws.amazon.com/rds/aurora/serverless/" rel="noopener" target="_blank">Amazon Aurora Serverless</a> v2 is now <a href="https://aws.amazon.com/about-aws/whats-new/2023/05/amazon-aurora-serverless-v2-additional-regions/" rel="noopener" target="_blank">available in four additional Regions</a>, expanding the reach of this scalable and cost-effective serverless database option. With Aurora Serverless v2, you can benefit from automatic scaling, pause-and-resume capability, and pay-per-use pricing, enabling you to optimize costs and manage your databases more efficiently.</p> 
<h2>Amazon SNS</h2> 
<p><a href="https://aws.amazon.com/sns/" rel="noopener" target="_blank">Amazon SNS</a> now supports message data protection in five additional Regions, ensuring the security and integrity of your message payloads. With this feature, you can encrypt sensitive message data at rest and in transit, meeting compliance requirements and safeguarding your data.</p>
