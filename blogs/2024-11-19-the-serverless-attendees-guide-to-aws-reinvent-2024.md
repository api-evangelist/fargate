<p>This guide organizes the sessions into categories to help you find the content this is most relevant to you.</p> 
<h2>Session Types</h2> 
<ul> 
 <li><strong>Breakout Sessions</strong> are lecture-style presentations covering architecture, best practices, and deep dives into AWS services.</li> 
 <li><strong>Workshops</strong> are 2-hour hands-on sessions where you work through tasks in AWS accounts using AWS services. Laptops are required and AWS credits are provided.</li> 
 <li><strong>Chalk Talks</strong> are highly interactive 60-minute sessions with smaller audiences, focused on technical deep dives with whiteboards for architectural discussions.</li> 
 <li><strong>Builders’ Sessions</strong> are 60-minute small-group sessions led by an AWS expert who guides you through a technical problem using AWS services.</li> 
 <li><strong>Code Talks</strong> are 60-minute live coding sessions where AWS experts show how to build solutions using AWS services.</li> 
</ul>
